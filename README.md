# CogniPilot artwork

Vector and raster logos for CogniPilot, ZROS, and Rumoca.

[Download the media kit](cognipilot-media-kit.zip) for the current logo exports
and written guidelines.

## Logo exports

| Folder | Contents |
| --- | --- |
| [cognipilot](cognipilot/) | Color logos for light and dark backgrounds; black and white logos |
| [zros](zros/) | Full ZROS logos with the tagline ROS for Zephyr RTOS, plus standalone symbols |
| [rumoca](rumoca/) | Closely cropped Rumoca emblems for light and dark backgrounds |

Use SVG for websites, print layouts, and scalable graphics. All logo SVGs
contain vector paths, including lettering, and have transparent backgrounds.
Use the matching 1,200-pixel-wide transparent PNG where SVG is not supported.

[Read the brand guidelines](BRAND_GUIDELINES.md) for background selection,
clear space, colors, typography, and suggested minimum sizes.
The guidelines are a review edition.

## Repository archive

The original artwork, historical variants, mascot, and previews are preserved
in this repository. They are excluded from the public brand guide and media kit.

| Location | Contents |
| --- | --- |
| [sources/cognipilot](sources/cognipilot/) | Ten original SVG files, retained under their original filenames |
| [sources/zros](sources/zros/) | Original ZROS raster artwork |
| [sources/rumoca](sources/rumoca/) | Original Rumoca SVG and 500-pixel PNG artwork |
| [previews](previews/) | Branding guide, logo presentations, and the original CogniPilot SVG collection |

The existing root-level PNGs, including CogniPuppet, are retained in their
original form.

HCDF logo concepts are retained separately in [hcdf](hcdf/), including the
[sensing variants](hcdf/alternates/) and optional domain colors. See the
[rendition comparison](previews/hcdf-renditions.png) and
[color comparison](previews/hcdf-color-comparison.png). These concepts are
excluded from the brand guide and media kit.
