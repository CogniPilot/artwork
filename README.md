# CogniPilot artwork

Vector and raster logos for CogniPilot, ZROS, and Rumoca.

[Download the media kit](cognipilot-media-kit.zip) for the current logo exports
and written guidelines.

## Logo exports

| Folder | Contents |
| --- | --- |
| [cognipilot](cognipilot/) | Color logos for light and dark backgrounds; black and white logos |
| [zros](zros/) | Full ZROS logos with the tagline ROS for Zephyr RTOS, plus standalone symbols |
| [rumoca](rumoca/) | Closely cropped Rumoca emblems for light and dark backgrounds |

Use SVG for websites, print layouts, and scalable graphics. All logo SVGs
contain vector paths, including lettering, and have transparent backgrounds.
Use the matching 1,200-pixel-wide transparent PNG where SVG is not supported.

[Read the brand guidelines](BRAND_GUIDELINES.md) for background selection,
clear space, colors, typography, and suggested minimum sizes.
The guidelines are a review edition.
